# Workshop Activity 4: Inspecting Packets

This activity demonstrates how to retrieve hidden values from internet packets.

## Launch VM

1. Go to this [URL](https://apackets.com/).

2. Download the pcap file from the document and upload it onto the website.

## Challenge hints

1. Scroll through the packet flow. You'll see lots of different types of packets.
2. Keep a keen eye on the HTTP packets. How do you filter them? What might they contain?
3. There might be several Base64 values, but only one contains the flag.
